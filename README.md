# My_First_Project


 Medical Store Management System (C Language)

![Medical Store Banner](images/banner.png)

A *Console-based Medical Store Management System* built in *C language* for managing *medicines, suppliers, customers, billing, and reports* efficiently.  
It uses file handling to store data and offers a menu-driven interface for ease of use.
📜 Features

### *1. Supplier Management*
- Add new suppliers
- Update supplier details
- Search suppliers by name or ID
- View the full list of suppliers

### *2. Customer Management*
- Add new customers
- Update customer details
- Search customers by name or ID
- View the full list of customers

- ### *3. Medicine Management*
- Purchase new medicines
- Sell medicines with automatic stock deduction
- View current stock
- Search medicines by name or ID
- Auto low-stock reminder (when quantity < 10)

- ### *4. Billing*
- Generate bills with:
  - Customer name
  - Medicine name
  - Quantity & rate
  - Auto date & time
- Save bills to file for later viewing

- ### *5. Reports*
- Purchase reports
- Sales reports
- Daily sales report
- Daily purchase report
- Profit report
